# auto re-login werkt niet
wanneer je sessie verloopt (na 24u) wordt je niet automatisch teruggestuurd naar de vtk site om een nieuwe token te krijgen, je moet dus elke dag op de "student login" knop drukken

Normaal zou er elke keer als je de pagina opendoet je auth/login token moeten verwerkt worden, indien er een token aanwezig is zou je moeten worden teruggestuurd. De browser moet de token dus langer cachen dan dat we de token als 'valid' ervaren.

Liefst zou de token maar als 'actief' worden ervaren voor 1 dag, maar hij zou in de browser moeten blijven voor +-30 dagen (tenzij de token wordt vervangen door een nieuwe)
